# card-kakeibo

三井住友カードの「ご利用のお知らせ」メールを自動で読み取り、カードの利用額と支払予定を管理する自分用の家計簿サイト。

```
Gmail（ご利用のお知らせ）
   ↓ 10分ごとに自動で読み取る（Google Apps Script：gas/ フォルダ）
Firebase（Cloud Firestore）
   ↓
家計簿サイト（GitHub Pages）
```

くわしい仕様は [仕様書](docs/specification.md) を参照。

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | 次のお支払い額と支払日、先月の利用額と前月差、サブスク合計、要確認のお知らせ |
| 明細 | 月の合計と支払日。「リスト」と「カレンダー」を切り替え。検索・絞り込み |
| レポート | 「月」「年」で期間を切り替え、カテゴリ別の円グラフと月ごとの棒グラフ |
| 設定 | サブスク・カテゴリ（名前と色）の管理、ログアウト |

- 締め日・支払日：月末締め・翌月25日払い。25日が土日祝（年末年始を含む）なら翌営業日（`utils.js` の `PAYMENT_DAY` と `paymentDateOf`）。祝日は計算で求めている
- メールで読み取れなかった利用（海外での利用など）は「要確認」になるので、金額を手で入れる
- 手入力は右下の「＋」ボタンから
- サブスクと Gmail の利用が二重になった月は、どちらかの行を左にスワイプして「除外」にする（取り消し線で残り、合計には入らない）
- カテゴリの入力欄は、登録したカテゴリをプルダウンで表示する。入力した文字を含むものだけに絞り込み、空ならすべて表示。新しい文字で保存すると自動で登録される
- カテゴリ名を変えると、そのカテゴリの利用とサブスクもまとめて変わる
- デザインは [Apple Human Interface Guidelines](https://developer.apple.com/jp/design/) を参考にしている

## Firestore のコレクション

| コレクション | 内容 |
| --- | --- |
| `transactions` | カードの利用（Gmail・手入力）。`excluded` が true なら合計に入れない |
| `fixedCosts` | サブスク |
| `fixedOverrides` | サブスクの「この月だけ」の変更（`skipped`：除外、`amount`：金額） |
| `categories` | カテゴリ（`name`、`color`、`order`） |

セキュリティルールは、ログインした自分のアカウントだけが4つとも読み書きできるようにしておく。

## Gmail 取り込みの設定（最初に1回だけ）

### 1. Firebase の秘密鍵を作る
1. [Firebase コンソール](https://console.firebase.google.com) → `card-kakeibo` → 左上の歯車 →「プロジェクトの設定」
2. 「サービス アカウント」タブ →「新しい秘密鍵を生成」→「キーを生成」
3. JSON ファイルがダウンロードされる

> この JSON ファイルはデータベースを自由に操作できる鍵です。**GitHub には絶対にアップロードしない**でください。手順 4 で貼り付けたら、パソコンからも削除して大丈夫です。

### 2. Apps Script のプロジェクトを作る
1. <https://script.google.com> →「新しいプロジェクト」
2. 左上の「無題のプロジェクト」をクリックして、名前を `カード家計簿 取り込み` にする

### 3. コードを貼り付ける
1. エディタの `コード.gs` の中身をすべて消して、[`gas/Code.gs`](gas/Code.gs) の中身を貼り付ける
2. 左の歯車「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
3. エディタに戻り、`appsscript.json` の中身を [`gas/appsscript.json`](gas/appsscript.json) の中身に置き換える
4. 保存（Ctrl + S）

### 4. 秘密鍵を登録する
1. 歯車「プロジェクトの設定」→ 一番下の「スクリプト プロパティを追加」
2. プロパティ：`SERVICE_ACCOUNT`
3. 値：手順 1 の JSON ファイルをメモ帳で開き、**中身をすべて** コピーして貼り付ける
4. 「スクリプト プロパティを保存」

### 5. 読み取りのテスト
1. エディタ上部の関数の選択で `testParseLatestMail` を選び「実行」
2. 初回は「承認が必要です」→ 自分のアカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトなので、このように表示されます
3. 実行ログに、最新のメールの日付・お店・金額が出れば OK

### 6. 自動取り込みを開始
1. 関数の選択で `setup` を選び「実行」
2. 2026年10月1日以降のメールがまとめて登録され、以後は10分ごとに自動で取り込まれる
3. 実行ログに「登録 ○件」と出れば完了

## 補足

- 同じメールはメールの ID で判別しているので、二重に登録されない
- メールから取り込んだ利用を削除すると「削除済み」の印が付く（消すと次の取り込みでまた登録されるため）
- 取り込みの開始日や間隔は `gas/Code.gs` の `CONFIG` で変えられる
